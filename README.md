SWYNEX - Final Data Analytics Project

Project Overview

This project was completed as the final project of my Data Analyst Internship at SWYNEX Technologies.

The project analyzes the Online Retail dataset and combines data cleaning, exploratory data analysis, interactive dashboarding, and business insights.

 Problem Statement

The objective of this project is to analyze online retail transaction data to identify sales trends, top-performing products and countries, customer patterns, and other useful business insights.

 Dataset

Dataset: UCI Online Retail Dataset

The dataset contains online retail transaction records including:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

 Data Cleaning

The dataset was cleaned using Python and Pandas.

Steps included:

- Missing value analysis
- Duplicate detection
- Data type checking
- Removing cancelled transactions
- Removing invalid quantities
- Removing invalid prices
- Removing duplicate records
- Handling missing product descriptions
- Final data validation

 Exploratory Data Analysis

The following analyses were performed:

- Statistical analysis
- Total revenue analysis
- Quantity analysis
- Monthly revenue trends
- Top products by revenue
- Top countries by revenue
- Day-wise revenue analysis
- Quantity vs Revenue analysis
- Outlier identification

 Dashboard

An interactive Power BI dashboard was created containing:

- Total Revenue
- Total Quantity Sold
- Total Orders
- Unique Customers
- Unique Products
- Monthly Revenue Trend
- Top 10 Products by Revenue
- Top 10 Countries by Revenue
- Quantity vs Revenue
- Country, Year, and Product filters
 Key Business Insights

- Revenue varies across different months.
- A small number of products contribute significantly to overall revenue.
- The United Kingdom contributes the largest share of revenue.
- Revenue differs across countries and days.
- Some transactions show unusually high revenue values.

This project demonstrates the complete data analytics workflow from raw data cleaning to exploratory analysis, visualization, dashboard development, and business insight generation.
